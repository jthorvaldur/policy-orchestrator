# Outputs

## HTML Timelines

**Repo:** `caseledger/pipeline/reporting/timeline.py`

Generates chronological HTML pages showing all documents organized by month/year.

```bash
cd ~/GitHub/caseledger && uv run python -m pipeline.scripts.build_timeseries
```

**Output:** `reports/timeline_YYYY.html` (one per year)

**Features:**
- Grouped by month
- Shows: date, source_type, title, topics
- Tokyo Night color scheme
- Master index aggregating all years

## Court-Ready PDF Binder

**Repo:** `caseledger/pipeline/reporting/binder_generator.py`

Generates court-standard PDF documents with:
- Case caption (court, case number, parties)
- Exhibit labels (A, B, C...)
- Page numbers
- Table of contents
- Section priorities (must read, should read, reference)

**Tech:** Jinja2 templates → HTML → WeasyPrint → PDF

**Styling:**
- Font: Outfit (body), JetBrains Mono (headers/code)
- Layout: Letter size, 1in margins
- Court caption: centered, bold, uppercase

## CaseLedger API (JSON)

**Port:** 8000

All analysis available as JSON endpoints:

```bash
# Search with hybrid retrieval + reranking
POST /search → { results: [{score, title, date, source_type, content_preview}] }

# Fact management
GET /cases/{id}/facts → { facts: [{id, statement, confidence, category, sources}] }
GET /cases/{id}/facts/disputed → contradictions only

# Analysis
GET /cases/{id}/cycles → { betti_number, cycles: [{severity, days_active, circuit_breakers}] }
GET /cases/{id}/consistency/{party} → { timeline: [{date, score, event}] }
GET /cases/{id}/audit?deep=true → { items: [{requirement, status, statute}], score }
GET /cases/{id}/deadlines → { items: [{obligation, due_date, status, priority}] }

# Chain building (logical proofs)
POST /cases/{id}/chain → { chain: [{type, fact_id, statement, confidence}], overall_confidence }

# Natural language Q&A
POST /cases/{id}/ask → { answer, supporting_documents, chain, search_results }

# Graph
GET /cases/{id}/graph → full hypergraph as JSON
GET /cases/{id}/graph/obligations → obligation subgraph (for cycle detection)
```

## Attack Vector Reports

Generated by combining analysis modules:

1. **Contradiction Report** — All detected contradictions with evidence chains
2. **Cycle Report** — Obligation loops with circuit breaker recommendations
3. **Disclosure Gap Report** — What's missing vs what's required
4. **Financial Reconciliation** — Claimed vs actual with gap percentages
5. **Cumulative Inconsistency Timeline** — Per-party score progression

Each report can be rendered as:
- JSON (API consumption)
- HTML (browser viewing)
- PDF (court filing via WeasyPrint)
